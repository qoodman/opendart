# 서버로 돌리기 (오라클 클라우드, 부동산 앱과 같은 서버)

맥을 켜두지 않아도 매일 저녁 새 공시를 받아 분석하고, 폰에서 결과를 보고 알림을 받기 위한 안내입니다.
부동산 앱(`realestate`)을 이미 서버에 올려 두었다는 전제입니다. 서버·Tailscale·ntfy를 그대로 같이 씁니다.

```
[오라클 서버]  realestate.xxxx.ts.net (부동산)   +   dart.xxxx.ts.net (DART, 매일 자동 수집 · 시각은 설정에서)
     │  Tailscale (나만 접속 가능한 사설망)
[안드로이드 폰]  홈 화면 아이콘 2개  +  ntfy 알림 (같은 주제로 같이 받음)
```

## 1. 서버에 올리기 (맥에서, 10분)

맥 터미널에서 실행합니다. 서버 주소와 키는 부동산 앱 때와 같습니다.

```bash
git clone https://github.com/qoodman/opendart.git ~/opendart   # 처음 한 번
cd ~/opendart
./scripts/push_to_server.sh ubuntu@서버IP ~/.ssh/oracle.key --with-data
```

이 명령이 하는 일:
- 서버에 코드를 받고 설치합니다 (`~/opendart`).
- **--with-data**: 맥 앱이 받아 둔 원문(`문서/DART단순투자/dart_cache`)을 서버로 복사합니다. 서버가 처음부터 수만 건을 다시 받지 않아도 됩니다.
- 맥 앱에 넣어 둔 **API 키**를 서버 설정(`.env`)에 넣습니다.
- 부동산 앱의 **ntfy 주제**와 **Tailscale 주소**를 찾아 자동으로 설정합니다.
- 매일 자동 수집(기본 20:13, 대시보드 **설정**에서 바꿈)과 대시보드를 등록합니다.

중간에 **DART 전용 Tailscale 로그인 주소**가 한 번 나옵니다. 브라우저에서 열고 **폰과 같은 계정**으로 로그인하세요.
마지막에 `폰 대시보드: https://dart.xxxx.ts.net` 같은 **DART 전용 주소**가 나옵니다. 부동산 주소(`realestate.xxxx.ts.net`)와 따로입니다.

> 같은 서버지만 Tailscale에는 `dart`라는 기기가 하나 더 생깁니다. Tailscale 관리 화면(login.tailscale.com → Machines)에서
> `dart` 옆 **⋯ → Disable key expiry**를 눌러 두면 180일마다 다시 로그인할 필요가 없습니다(부동산 서버도 마찬가지).

## 2. 접속 확인 (일본 서버라면 꼭)

```bash
ssh -i ~/.ssh/oracle.key ubuntu@서버IP "~/opendart/.venv/bin/python ~/opendart/dart_server.py net-check"
```
- 모두 ✔이면 그대로 진행합니다.
- **DART OpenAPI에 ✖**가 나오면 해외 접속이 막힌 것입니다. 부동산 앱 안내의 **"한국 서버가 필요할 때"**(AWS Lightsail 서울)를 보세요.
- **네이버 증권에 ✖**만 나오면 종가 칸만 비고 나머지는 정상으로 돌아갑니다.

## 3. 첫 수집

```bash
ssh -i ~/.ssh/oracle.key ubuntu@서버IP
sudo systemctl start --no-block dart-daily
journalctl -u dart-daily -f        # 진행 상황 보기 (Ctrl+C로 보기만 끔, 수집은 계속됨)
```
- 30초마다 `♥` 생존 신호 줄이 찍힙니다. 폰 대시보드에서도 진행 막대로 보입니다.
- **첫 수집은 알림을 보내지 않고 기준선만 저장**합니다. 다음 날부터 새로 들어온 공시를 알려줍니다.
- 원문을 복사하지 않았다면 처음엔 오래 걸리고, 하루 호출 한도를 넘으면 다음 날 이어서 받습니다.

## 4. 폰에서 열기

1. 폰에서 Tailscale을 켠 상태로 1번에서 나온 주소(`https://dart.xxxx.ts.net`)를 크롬에서 엽니다.
2. 크롬 메뉴(⋮) → **홈 화면에 추가**. 부동산 아이콘 옆에 파란 막대그래프 아이콘이 생깁니다.
3. 대시보드 위쪽 **부동산 ↗** 링크로 부동산 대시보드로 바로 갈 수 있습니다.

| 아이디어 | (매도 단가·실현 차익·남은 잔량과 '아직 안 판 곳만' 필터 포함) **기관 평단보다 싼 종목**(최근 종가 기준), **여러 기관이 함께 산 종목**. 막대그래프·추세선, 증권사 목표가·상승여력 |
| 피터 린치 · 워렌 버핏 (아이디어 탭) | 기관이 산 종목을 두 사람의 방법을 재무 숫자로 옮겨 점수 냄. 린치: 6가지 유형 분류 + PEG(PER÷이익 성장률) · 버핏: ROE·부채비율·이익 꾸준함·영업이익률·가격·성장. 네이버 연간 재무(최근 3개 확정 연도)를 주 1회 받음. 단순 점수라 실제 두 사람의 판단과 다름, 투자 추천 아님 |

| 종목 화면 | 주가 그래프(기관 매수 지점·기관 평단·증권사 평균 목표가), 한경컨센서스 리포트 목록, 모든 매수·매도 내역 · 날짜별 평균 매수단가·모든 변동 내역은 10줄씩 번호 페이지, 변동일별·제출일별·보고자별로 묶어 보기 |
| 지금 수집 | 기다리지 않고 바로 수집 시작 |

## 증권사 리포트 (한경컨센서스 · 네이버 증권)

매일 수집이 끝나면 두 곳의 기업 리포트 목록(날짜·증권사·목표가·의견·제목·PDF 링크)을 받아 **리포트** 화면에 모읍니다.
- 한경컨센서스: 처음 180일, 이후 새 것만. 목록에 목표가가 바로 나옵니다.
- 네이버 증권: 처음 30일, 이후 새 것만. 목표가·투자의견은 리포트마다 상세 화면에서 읽습니다(한 번에 최대 400건, 나머지는 다음 수집 때).
- 종목 화면의 **목표가 평균**은 두 곳을 합쳐 증권사마다 가장 최근 목표가(최근 6개월)로 계산합니다.

설치 후 한 번 확인해 보세요.
```bash
~/opendart/.venv/bin/python ~/opendart/dart_server.py reports-check 005930
```
- 출처마다 `✔ 저장된 리포트 …건`이 나오면 정상입니다.
- `✖ … 형식을 읽지 못했습니다`가 나오면 그 사이트 화면이 바뀐 것입니다. 메시지(확인용 파일 위치 포함)를 알려주세요.
- 출처별로 켜고 끄기는 대시보드 **설정 → 수집**에서 합니다.

## 시장 · 정책

부동산 앱의 시장·정책 화면을 주식용으로 옮긴 것입니다. 같은 서버의 부동산 앱 `.env`에 있는 키(ECOS_API_KEY, DATA_GO_KR_KEY,
LAW_OC, ASSEMBLY_API_KEY)를 그대로 씁니다. 이 앱 `.env`에 따로 넣으면 그 값이 우선입니다.
- 키 없이도 코스피·코스닥 추세와 우리 데이터(기관 매수 흐름·목표가 상향/하향) 지표는 나옵니다.
- 확인: `.venv/bin/python dart_server.py market-check`
- 새 정책 소식은 ntfy로 알립니다 (첫 수집은 기준선). 설정 → 시장·정책에서 끌 수 있습니다.

## KRX Open API 키

한국거래소(KRX) 데이터를 쓸 때 필요한 키입니다. 발급은 openapi.krx.co.kr → 회원가입·로그인 → 마이페이지 → API 인증키 신청.
키 승인과 별개로 **서비스 이용신청**에서 쓸 서비스를 서비스마다 신청하고 승인받아야 그 서비스를 부를 수 있습니다.

- 대시보드 **설정** 맨 위 쪽의 **KRX Open API 키** 칸에 붙여넣고 저장 (화면에는 앞뒤 4자리만 보입니다).
- 또는 서버에서 `.venv/bin/python dart_server.py set-env KRX_API_KEY` 를 실행하고 키를 입력.
- 키는 서버 `.env`(권한 600)에만 저장되고 GitHub에는 올라가지 않습니다.

### KRX 시세와 대차거래 (설정 → 연결 확인)

- **KRX 시세** (유가증권·코스닥 일별매매정보): 매일 시장·정책 수집 때 최근 거래일 시가총액·상장주식수·거래대금을 받습니다. 종목 화면과 아이디어 카드에 시총·거래대금·'기관 매수금액이 시총의 몇 %'가 나오고, 5% 공시에서 읽은 보유비율을 상장주식수로 다시 계산해 맞는지 확인합니다. KRX 키와 해당 서비스 이용 승인이 필요합니다.
- **주식 대차거래** (공공데이터포털 '금융위원회_주식대차거래정보'): 종목별 대차잔고(빌려 간 주식 수)와 5거래일 변화를 종목 화면·아이디어 카드에 보여 줍니다. 공매도 잔고와 같은 숫자는 아닙니다. 정책 수집에 쓰는 공공데이터포털 키(`DATA_GO_KR_KEY`)를 쓰고, 이 데이터셋의 **활용신청**이 승인돼야 합니다.
- 설정의 **외부 데이터 연결 확인**에서 'KRX 확인'·'대차거래 확인'을 누르면 키와 서비스가 되는지, 받은 응답의 필드 이름이 무엇인지 보여 줍니다. 이상하면 그 화면을 캡처해서 보내 주세요.
- 끄려면 `.env`에 `DART_KRX=0` 또는 `DART_LENDING=0`.

## 5. 알림

부동산 앱과 같은 ntfy 주제를 쓰므로 **폰에서 따로 설정할 게 없습니다.** 새 공시가 있는 날 저녁에 이렇게 옵니다.

시험: `~/opendart/.venv/bin/python ~/opendart/dart_server.py notify-test`

## 백업

**서버:** 매일 새벽 3시에 `~/backups/`에 날짜별 백업을 만들고, 최근 7개만 남겨요. 백업에는 결과 데이터베이스, 원문 캐시, 설정(`.env`, API 키 포함), 업데이트·알림 기록이 들어 있어요. 지금 바로 만들려면: `~/opendart/scripts/backup_server.sh`

**맥:** 맥에서 `./scripts/backup_to_mac.sh ubuntu@서버IP ~/.ssh/oracle.key`를 실행하면 서버 백업을 새로 만들어 `~/opendart-backup/`으로 내려받아요. 맥에는 최근 30개를 남겨요. 맥을 켜 둔 때만 되고 자동으로 돌지는 않아요.

**복원:** 백업 파일을 풀고(`tar -xzf 파일`), `results.sqlite`와 `dart_cache`를 서버의 데이터 폴더(`~/opendart/data`)에 넣은 뒤, `env.txt`를 `~/opendart/.env`로 복사하면 돼요.

## 문제가 생기면

- **평균단가가 이상함**: 설정 맨 아래 **분석 점검** → 예전 방식이 남았으면 **지금 수집 → 다시 분석만**, 그래도 이상한 공시는 눌러서 표를 캡처해 보내 주세요.

- **대시보드가 안 열림**: 폰의 Tailscale이 켜져 있는지 확인합니다. 서버에서 `systemctl status dart-web tailscaled-dart`로 둘 다 active인지 봅니다.
- **수집 실패 알림이 옴**: 서버에서 `journalctl -u dart-tick -u dart-daily -n 50`으로 이유를 봅니다. "호출 한도"면 다음 날 자동으로 이어서 받습니다.
- **부동산 앱이 느려짐**: DART 수집은 낮은 우선순위로 돌고 부동산 수집(19:17)과 시간이 겹치지 않게 20:13에 돕니다. 그래도 느리면 대시보드 **설정 → 성능**에서 동시 다운로드 수를 2로 줄이세요.
