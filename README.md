# autotrader

한국투자증권(KIS) Open API로 국내주식, 국내 ETF, 미국주식을 **중빈도**(1분봉 기준)로 자동매매하는 기본 골격입니다.
수수료와 세금을 먼저 계산하고, 비용을 넘기 어려운 매매는 자동으로 막습니다.

> 예시 전략은 구조를 보여주기 위한 것이며 수익을 보장하지 않습니다. 모의투자에서 충분히 검증한 뒤 소액으로 시작하세요.

## 구조

```
autotrader/
  fees.py        수수료·세금·호가단위, 왕복 비용 계산
  models.py      종목·주문·포지션·봉
  oms.py         주문·포지션 관리, 수수료 차감 손익
  risk.py        주문 전 검사, 일일 손실 한도, 킬 스위치
  strategy/      전략 (봉 → 신호). 예시: 수수료 고려 돌파 전략
  backtest.py    CSV 봉 데이터 백테스트 (다음 봉 시가 체결 + 슬리피지)
  engine.py      실시간 엔진: 웹소켓 → 1분봉 → 전략 → 리스크 → 주문
  kis/           KIS 인증(토큰 캐시), REST(호출 제한·재시도), 웹소켓(시세·체결통보)
```

같은 전략 코드가 백테스트, 모의투자, 실전에서 그대로 돕니다.

## 빠른 시작

```bash
pip install -e ".[dev]"
python -m autotrader costs                       # 시장별 왕복 비용 확인
python -m autotrader sample-data sample.csv      # 연습용 가짜 데이터
python -m autotrader backtest sample.csv -s 005930:KRX_STOCK -s 069500:KRX_ETF -s AAPL:US:NASD
pytest
```

모의투자 실시간 실행:

```bash
cp .env.example .env    # 키 입력
python -m autotrader run -s 005930:KRX_STOCK -s 069500:KRX_ETF
```

종목 형식: `코드:KRX_STOCK`, `코드:KRX_ETF`, `티커:US:NASD|NYSE|AMEX`

## 수수료 모델 (기본값, `fees.py`의 `DEFAULT_FEES`)

| 시장 | 매수 | 매도 |
|---|---|---|
| 국내 주식 | 수수료 0.015% | 수수료 0.015% + 거래세(농특세 포함) 0.20% |
| 국내 ETF | 수수료 0.015% | 수수료 0.015% (거래세 면제) |
| 미국 주식 | 수수료 0.25% | 수수료 0.25% + SEC fee + FINRA TAF |

- 실제 계좌 수수료(이벤트 등)와 그해 세율로 꼭 바꾸세요. `FeeModel.with_override()`를 쓰면 됩니다.
- 슬리피지는 매수·매도 각 1호가로 가정합니다 (`--slippage`).
- 환전 비용은 기본 0입니다(달러를 계속 보유한다고 가정). 매번 환전하면 `fx_spread_rate`를 넣으세요.
- 연간 세금(해외주식 양도소득세, 해외지수 ETF 배당소득세 등)은 거래마다 내는 비용이 아니라서 포함하지 않았습니다.

**비용 관문**: 진입 신호의 기대수익이 `왕복비용 × min_edge_multiple`(기본 2배)보다 작으면 리스크 관리에서 주문을 거부합니다.
국내 주식은 매도세 때문에 왕복 0.5% 안팎이 들어서 아주 짧은 단타는 거의 막힙니다. 반면 국내 ETF는 비용이 낮아 짧은 매매에 유리합니다.

## 안전장치

- 기본은 **모의투자**입니다. 실전은 `--live`와 `KIS_ALLOW_LIVE=yes`를 둘 다 설정해야 합니다.
- 손실 한도: 하루 손실(실현+평가, 수수료 포함)이 `--max-daily-loss`에 닿으면 신규 진입을 멈춥니다. 청산 매도는 계속 허용합니다.
- 킬 스위치: 작업 폴더에 `KILL` 파일을 만들면(`touch KILL`) 신규 매수를 멈추고 미체결 매수를 취소합니다.
- 그 밖에 주문 1건, 종목당, 전체 보유 금액 한도와 분당 주문 수 제한이 있습니다. 공매도는 막혀 있습니다.
- 미체결 주문은 30초 뒤 자동 취소합니다.
- 주문 응답이 타임아웃되면 접수 여부를 알 수 없으므로 신규 진입을 멈춥니다.

## 실전 전 확인할 것 (아직 검증 안 됨)

- **실제 KIS 서버로는 테스트하지 않았습니다.** 테스트는 가짜 서버로만 돌렸습니다.
- 웹소켓 메시지의 필드 위치(`kis/ws.py`의 `*_IDX`)와 거래ID(`kis/rest.py`의 `TR`)는 KIS 문서 기준입니다.
  모의투자에서 `-v` 옵션으로 원본 메시지를 보고 한 번 확인하세요. 특히 해외 체결통보가 중요합니다.
- 국내 주문은 시장가로, 미국 주문은 기준가 ±0.5% 지정가로 나갑니다 (KIS 미국 주식은 지정가 위주).
- 시작할 때 국내 잔고만 읽어 포지션을 맞춥니다. 미국 잔고 동기화는 아직 없습니다.
- 장 운영시간 확인, 동시호가와 VI 처리, 공휴일 처리는 아직 없습니다.
